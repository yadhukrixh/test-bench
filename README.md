# QA Workbench

Phase 7 is a native macOS app. It can check this Mac, boot or stop an Android emulator and an iOS simulator, show the live picture, dump the Android hierarchy, capture PNG plus XML snapshots, run or attach a Flutter project with hot reload, list HTTP from the Dart VM profile, the emulator HTTP proxy, and on-device DNS/TLS capture, and read on-screen text with Vision and on-device translation. On Android you can tap, press Back or Home, change volume, rotate, read and set the clipboard, select a node, and install and open an APK from this Mac, from an http or https address, or from a file already on the emulator.
