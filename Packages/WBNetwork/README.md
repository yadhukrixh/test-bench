# WBNetwork

VM HTTP profile for debug and profile Flutter (`flutter run` or `flutter attach`). Poll `ext.dart.io.getHttpProfile` and fetch bodies with `getHttpProfileRequest`. Installed and native Android HTTP is captured with mitmdump on `127.0.0.1:18080` and `adb shell settings put global http_proxy 10.0.2.2:18080`. HTTPS is passed through (`tls_clienthello` `ignore_connection`) so guest apps keep internet; CONNECT hosts still appear. Cleartext HTTP is still intercepted. Dart and other clients that ignore `http_proxy` are listed from an on-device VPN capture (PCAPdroid `tcp_exporter` to `127.0.0.1:18081` via `adb reverse`): DNS names, TLS SNI, and cleartext HTTP. SOCKS5 MITM is off because Flutter does not trust a user CA and that path showed a no-network screen. VM, proxy, and packet rows that share method, URL, optional status, and a start time within 250 ms are merged. Release Flutter has no VM service; Blutter is not used.
